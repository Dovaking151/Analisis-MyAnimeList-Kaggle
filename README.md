Descripción del Proyecto
Este proyecto consiste en un análisis exhaustivo de un dataset masivo obtenido de Kaggle sobre la plataforma MyAnimeList. El objetivo principal fue limpiar, estructurar y analizar datos históricos para identificar la evolución de las preferencias de los usuarios y las tendencias de géneros en la industria del anime durante un periodo de 14 años.

Herramientas Utilizadas
Google Sheets: Herramienta principal para el procesamiento, limpieza y análisis de datos en la nube.

Kaggle: Fuente del dataset original.

Habilidades Técnicas Aplicadas
Limpieza de Datos: Tratamiento de valores nulos, eliminación de duplicados y estandarización de formatos para asegurar la integridad de la información.

Funciones Avanzadas: Implementación de fórmulas complejas como INDEX, MATCH y FILTER para la organización eficiente de miles de registros.

Análisis Exploratorio: Identificación de patrones temporales y comportamiento de usuarios mediante el uso de tablas dinámicas y segmentación de datos.

Hallazgos Clave
Evolución de Géneros: Se detectaron cambios significativos en la popularidad de ciertos géneros entre los años 2004 y 2018.

Tendencias de Usuario: El análisis permitió visualizar el crecimiento de la base de usuarios y sus hábitos de calificación a través del tiempo.
